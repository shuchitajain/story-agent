# Examples

Sample output files generated by story-agent for a real-world story run.

```
outputs/PROJ-2356/
├── story.md              — verbatim story details fetched from the tracker
├── explanation.md        — plain-English brief (≤150 words) and likely impact preview
├── analysis.md           — 5-lens analysis with TL;DR (architecture, state, edge, testing, rollback)
├── decisions.md          — answered questions ledger (PM + Engineering, with implications)
├── plan.md               — taskized implementation brief (3 tasks, each ≤3 files)
├── execution-state.json  — machine-readable task state skeleton written at plan time
├── validation.md         — per-task validation receipt skeleton written at plan time
└── manual-todo.md        — access failures and story gaps that need manual follow-up
```

These files mirror the full output contract under `.ai/story-agent/outputs/stories/<id>/`.
The implementation agent fills in `execution-state.json` and `validation.md` as tasks complete.
